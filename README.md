# Fastfetch for AROS

Port workspace for [Fastfetch](https://github.com/fastfetch-cli/fastfetch).
This repository currently contains the source pin and port instructions.
**There is no working AROS port or release yet.**

The initial upstream baseline is 2.70.0. Targets are x86_64 ABIv1 and ABIv11;
Raspberry Pi AArch64 is a separate target, not a generic AArch64 compatibility claim.

See [development](docs/development.md) and [patch workflow](docs/patching.md).
